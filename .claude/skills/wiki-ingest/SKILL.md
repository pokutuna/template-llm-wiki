# 外部資料の取り込み

対象: $ARGUMENTS

`sources/` には、後の作業で元の資料を探して読み直さなくても内容を使えるように、外部資料の内容を取り込む。
ページは `wiki-write` skill の「ページの書き方」に従って書き、取り込みに固有のことはこの skill に従う。

## 手順

資料 (記事、論文、ドキュメントのページなど) ごとに次を行う。

1. 同じ資料が取り込み済みか探す: `rg '^resource: <資料の URL>' wiki/sources`。取り込み済みなら、そのページを資料の今の内容で更新する
2. 資料の原文を読む。読めないときは推測で書かず、ユーザーに内容を貼ってもらう
3. 「書き方」に従って `wiki/sources/` にページを書く

## 書き方

本文には資料に書いてあることだけを書き、この wiki の知識や解釈は書かない。

- ファイル名: 資料の題名を短くした kebab-case (例: `example-docs-configuration.md`)
- `title`: 資料の題名
- `description`: 資料の発行元と、何について書かれた資料か
- `resource`: 資料の URL
- `tags`: 資料が扱う主題
- 本文: 資料の内容を説明・要約する。図や表にしか書かれていない情報も文章にする。資料に公開日や更新日があれば書く
